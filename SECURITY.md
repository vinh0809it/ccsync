# Security policy

ccsync encrypts everything it stores; a flaw that exposes session content,
metadata or the store key, lets a store writer escape the Claude Code
directory, or lets another local user drive the GUI is a security issue.

Please report it privately through
[GitHub's private vulnerability reporting](https://github.com/vinh0809it/ccsync/security/advisories/new)
rather than a public issue. You'll get a reply within a week.

The threat model is described in the README ("Security model").
